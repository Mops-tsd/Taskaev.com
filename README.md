# Alexander Taskaev — Strategy &amp; Development

Одностраничный сайт-визитка Александра Сергеевича Таскаева: стратегия, девелопмент
и международная кооперация (TSD Group / AP TRADE).

Статический сайт без сборки — открывается напрямую и хостится где угодно
(GitHub Pages, Netlify, Vercel, любой статический хостинг).

## Структура

```
index.html          — разметка страницы (контент по умолчанию — RU)
assets/styles.css    — дизайн-система, адаптив, анимации
assets/main.js       — интерактив: языки, меню, анимации появления, счётчики, форма
assets/data.js       — переводы RU / EN / 中文 / العربية (window.I18N)
assets/social-card.svg — превью для соцсетей (og:image)
```

## Возможности

- Адаптивный дизайн, полностью переработанная мобильная версия
  (полноэкранное меню, без горизонтального скролла, safe-area, крупные тач-зоны).
- Анимации: живой градиентный фон, появление секций при скролле,
  счётчики цифр, бегущая строка, прогресс-бар, микровзаимодействия.
  Всё уважает `prefers-reduced-motion`.
- 4 языка с корректным RTL для арабского. Выбор языка сохраняется в браузере.
- Форма обращения открывает письмо на рабочий адрес (mailto).

## Как редактировать контент

Тексты для всех языков лежат в `assets/data.js` (объект `window.I18N`).
Разметка в `index.html` помечена атрибутами `data-i18n="ключ"` — JS
подставляет перевод по ключу. Ссылки на проекты и новости — прямо в `index.html`.

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```
