# Заявки с сайта в Telegram — настройка

Форма на сайте отправляет заявку в Telegram мгновенно. Настройка занимает ~5 минут
и делается **один раз**. Нужны два значения: токен бота и ID чата.

---

## Шаг 1. Создать бота

1. В Telegram найдите **@BotFather** и напишите ему `/newbot`
2. Придумайте имя бота, например `Заявки — Александр Таскаев`
3. Придумайте логин бота, он должен заканчиваться на `bot`, например `taskaev_leads_bot`
4. BotFather пришлёт **токен** — длинную строку вида:

```
7123456789:AAF9x-ExampleTokenHere_abcdefGHIjkl
```

Это `bot_token`. Никому его не показывайте — по нему можно писать от имени бота.

---

## Шаг 2. Узнать chat_id

Выберите, куда должны приходить заявки.

### Вариант А — в личные сообщения Александру Сергеевичу

1. Александр Сергеевич находит созданного бота по логину и нажимает **«Запустить» / Start**
   (без этого бот не сможет ему написать — так устроен Telegram)
2. Откройте в браузере ссылку, подставив свой токен:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. В ответе найдите `"chat":{"id":123456789` — это число и есть `chat_id`

### Вариант Б — в группу (рекомендуется)

Удобнее, если заявки видят несколько человек — например, Александр Сергеевич и помощник.

1. Создайте группу в Telegram, добавьте нужных людей
2. Добавьте туда бота как участника
3. Напишите в группе любое сообщение
4. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
5. Найдите `"chat":{"id":-1001234567890` — у групп ID **отрицательный**, минус тоже копируем

---

## Шаг 3. Прописать значения на сайте

Создайте на хостинге рядом с `send.php` файл **`config.php`**:

```php
<?php
return [
    'bot_token' => '7123456789:AAF9x-ExampleTokenHere_abcdefGHIjkl',
    'chat_id'   => '123456789',
    'email_to'  => 'a.taskaev@tsr-gr.ru', // дубль на почту; оставьте пустым, если не нужно
    'site_name' => 'taskaev.ru',
];
```

Готово. Заявки начнут приходить в Telegram.

> **Почему отдельный файл:** `config.php` не хранится в репозитории с кодом,
> поэтому токен не попадёт к посторонним. При обновлении сайта этот файл не трогают.

---

## Шаг 4. Проверить

1. Откройте сайт → раздел «Контакты»
2. Заполните форму тестовыми данными и отправьте
3. В Telegram должно прийти сообщение вида:

```
📩 Новая заявка с сайта

Имя: Иван Петров
Компания: ООО «Пример»
Контакт: +7 900 000-00-00

Задача:
Хотим обсудить участие в проекте.

taskaev.ru · 28.07.2026 14:30
```

## Что уже встроено

| Возможность | Как работает |
|---|---|
| **Отправка в Telegram** | Мгновенно, с форматированием |
| **Дубль на почту** | Одновременно уходит на рабочий адрес |
| **Защита от спама** | Скрытое поле-ловушка для ботов |
| **Защита от флуда** | Не чаще одной заявки в 30 секунд с одного адреса |
| **Согласие на обработку данных** | Обязательная галочка (152-ФЗ) |
| **Запасной вариант** | Если PHP недоступен — откроется почтовая программа |

---

## Если заявки не приходят

- **«Telegram не настроен»** — не заполнены `bot_token` или `chat_id` в `config.php`
- **Бот не пишет в личку** — получатель не нажал Start у бота (Шаг 2, вариант А)
- **Пустой ответ у `getUpdates`** — напишите боту (или в группу) любое сообщение и обновите страницу
- **Ошибка 502** — хостинг блокирует внешние запросы; напишите в поддержку хостинга,
  попросите открыть доступ к `api.telegram.org`
- **Форма открывает почтовую программу** — значит `send.php` не отработал:
  проверьте, что файл загружен на сервер и на хостинге включён PHP

---

## Требования к хостингу

- PHP 7.4 и новее
- Разрешены исходящие HTTPS-запросы (нужно для `api.telegram.org`)
- Желательно расширение cURL (если его нет — сработает запасной способ)

Обычный тариф Timeweb / Beget / reg.ru подходит без доработок.
